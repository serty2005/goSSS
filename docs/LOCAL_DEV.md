# Локальный запуск (без Docker)

Ниже — быстрый и повторяемый способ запустить проект локально на машине разработчика.

## Требования

- Go 1.23+
- PostgreSQL 15/16+
- Node.js 20+ и npm

## 1. Подготовка базы данных

Создайте пользователя и базу (пример через psql):

```sql
CREATE USER etalon WITH PASSWORD 'etalon';
CREATE DATABASE etalon_db OWNER etalon;
GRANT ALL PRIVILEGES ON DATABASE etalon_db TO etalon;
```

Проверьте, что строка подключения в `DATABASE_URL` указывает на вашу БД.

## 2. Бэкенд

1. Скопируйте файл окружения:

```bash
cp .env.example .env
```

2. При необходимости измените `DATABASE_URL`, `JWT_SECRET`, `ADMIN_*`.

3. Установите зависимости и запустите сервер:

```bash
go mod tidy
go run ./cmd/etalon-server/main.go
```

Сервер стартует на `http://localhost:8080` (или на порту из `PORT`).
Миграции и создание админ-пользователя выполняются автоматически.

## 3. Фронтенд

1. Подготовьте переменные окружения:

```bash
cp front-ui/.env.example front-ui/.env.local
```

2. Установите зависимости и запустите dev-сервер:

```bash
cd front-ui
npm install
npm run dev
```

Фронтенд будет доступен на `http://localhost:5173` и будет проксировать `/api` на бэкенд.

## 4. Примечания

- По умолчанию интеграции и фоновые воркеры отключены в `.env.example`.
  Включайте их точечно, когда будут доступны внешние сервисы.
- Команда `--seed` требует наличие данных в `tools/seeder/mock_data`.
  Сейчас этот каталог в репозитории отсутствует, поэтому сидинг запускать не следует,
  пока данные не будут добавлены.
