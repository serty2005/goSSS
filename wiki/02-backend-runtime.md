# 02. Backend: запуск и жизненный цикл приложения

## Вход и bootstrap

- Точка входа: `cmd/etalon-server/main.go`.
- Основная сборка: `internal/app/app.go`.

## Последовательность инициализации

1. Загрузка конфигурации из `.env`.
2. Подключение к PostgreSQL.
3. `AutoMigrate` доменных моделей.
4. Создание репозиториев и инфраструктурных клиентов.
5. Создание бизнес-сервисов.
6. Регистрация HTTP handlers и middleware.
7. Запуск фоновых процессов и HTTP-сервера.

## Практическая проверка при изменениях

Перед изменением runtime-логики проверить:

- влияние на порядок инициализации (нет ли скрытых зависимостей);
- graceful shutdown через `context.Context`;
- ошибки и логи на русском языке;
- флаги `ENABLE_*` для опциональных модулей.
