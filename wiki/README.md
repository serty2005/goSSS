# Wiki репозитория goSSS

Этот раздел — стартовая точка внутренней wiki по проекту. Цель — фиксировать **реальное состояние кода**, а не желаемую архитектуру.

## Принципы актуализации

1. Любая статья ссылается на конкретные файлы и пакеты репозитория.
2. Если поведение расходится со старым документом — приоритет у кода.
3. Для спорных мест в статьях оставляется блок «Открытые вопросы».
4. В wiki не публикуются секреты, токены и реальные production-значения.
