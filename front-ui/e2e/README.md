# Playwright-тестирование фронтенда

E2E-контур проверяет UI ServiceDesk через Vite-приложение и стабильные route-моки API. Логин в сценариях выполняется через форму с учетными данными `admin/admin`.

## Команды

```bash
npm run test:e2e
npm run test:e2e:headed
npm run test:e2e:ui
npm run test:e2e:report
```

По умолчанию Playwright сам запускает Vite на `127.0.0.1:5178`, чтобы не конфликтовать с обычным dev-сервером.

## Переменные окружения

- `PLAYWRIGHT_PORT` - порт локального Vite-сервера, по умолчанию `5178`.
- `PLAYWRIGHT_BASE_URL` - URL уже запущенного фронтенда.
- `PLAYWRIGHT_SKIP_WEBSERVER=1` - не запускать Vite из Playwright, использовать внешний сервер.
- `PLAYWRIGHT_REUSE_SERVER=1` - разрешить переиспользовать уже запущенный сервер на выбранном порту.

## Что проверяется

- форма входа, обязательные поля и успешный вход `admin/admin`;
- защищенный app shell, меню, профиль и настройки темы;
- таблица тикетов, быстрый просмотр заявки и данные подключений;
- отсутствие горизонтального скролла документа и выходящих за viewport ключевых блоков;
- отсутствие браузерных `pageerror` и `console.error` в тестируемых сценариях;
- desktop и mobile Chromium-проекты.
