# AGENTS.md

## Основные правила работы

1. Все ответы, комментарии в коде, логи и сообщения должны быть строго на русском языке.
2. Нельзя придумывать детали реализации, связанные с внешними системами или неоднозначными требованиями. Если информации недостаточно, нужно задать уточняющие вопросы и дождаться ответа, прежде чем писать код.
3. Комментарии в коде должны быть только актуальными. Не использовать пометки вроде "ОБНОВЛЕНО" или "ДОБАВЛЕНО". Комментировать только реальную текущую функциональность.
4. Весь русский текст обязательно должен быть в кодировке UTF-8. Не допускай символы, которые не входят в этот набор. Проверяй код после внесения правок на mojibake и исправляй некорректное отображение русского текста.
5. Актуальная документация к REST API Naumen стороны находится тут https://www.naumen.ru/docs/sd/Content/RESTful/REST_API_TOC.htm используй поиск по ней для получения точных данных
6. При генерации кода НИКОГДА не пиши в ISO-8859-1 / Windows-1252. ВСЕГДА пиши сразу в UTF-8.
7. Используй python-скрипт ./mojifix.py с путём к файлу для автоматического исправления почти всех сломов кодировки, когда возникает такая проблема 
8. Используй Docker-MCP Playwright для автоматического тестирования UI-изменений.
